# New client onboarding (payroll setup)

1. Receive the signed SOW and the intake form from the KAM.
2. Create the employer in SPARK, link the correct PC and set the RSZ number.
3. Request the historical data (YTD) and load it using the HDL template.
4. Do a parallel run for 2 months. Differences above EUR 2 per employee go into the recon file.
5. After sign-off by the client, move the client to Wave 1 or Wave 2 depending on the size (see the TLC rules).
6. Hand over to the run team with the GPO checklist.

## Tips
- Always double check the SSA flag for clients with student workers.
- Clients coming from a competitor often send the YTD file in the wrong format; ask for the XLS instead of the CSV.
