# Client communication (Wave 2 portfolio)

## Channels
- Client tickets come in via the HALO queue (category PAY-BE-W2). Pick them up within the SLA.
- Urgent requests from Wave 1 accounts go directly to the SPOC, cc the KAM.
- Never send payslip data by email; use the MyPortal secure share.

## Standard messages
- **VPI reminder** (T-5): use template TPL-07 in Nexus.
- **Late BLX** (after T-3): use TPL-11 and inform the client that the MOP fee may apply.
- **DHP simulation** (Wave 1 only): send the SIM-pack 2 weeks before the run.

## Monthly reporting to clients
- Send the KPI-pack to clients with the Gold SLA before WD5.
- For TLC-B clients, the KPI-pack is only on request.
- Escalations from clients go to the team lead; see the escalation procedure.

## Known issues
- Nexus sometimes duplicates TPL-11 emails; check the outbox before re-sending.
- Some clients still send BLX files by email; the GDC can load them manually (ask the usual contact).
