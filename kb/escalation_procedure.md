# Escalation procedure for payroll incidents

| Level | When | Who |
|-------|------|-----|
| P3 | Individual payslip error, no deadline impact | Payroll consultant fixes it within the SLA |
| P2 | Multiple employees impacted or SEPA file at risk | Team lead + KAM, log in ServiceNow |
| P1 | Payroll run not possible before T0 | Ops manager, CIM called, client informed by KAM |

- For P1 incidents, open a bridge call and inform the DPO if personal data is involved.
- Always do an RCA within 5 working days after a P1.
