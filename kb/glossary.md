# Glossary (Payroll Operations Belgium)

| Term | Meaning |
|------|---------|
| RSZ / ONSS | Belgian National Social Security Office |
| Dimona | Electronic declaration of employment start/end to the RSZ |
| DmfA | Quarterly multifunctional declaration of wages and working time to the RSZ |
| PC | Paritair Comité / Joint Committee - sector collective agreement that determines wage rules |
| GL | General Ledger |
| SLA | Service Level Agreement |
| KAM | Key Account Manager |
| PCR | Payroll Control Report - generated after each test run |
| SEPA | Single Euro Payments Area - bank payment file format |
| SPOC | Single Point Of Contact |
| KPI | Key Performance Indicator |
| DPO | Data Protection Officer |
| RCA | Root Cause Analysis |
