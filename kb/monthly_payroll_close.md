# Monthly payroll close (Wave 2 clients)

## Timeline
- **T-5**: Send the VPI reminder to all Wave 2 clients. Clients that did not deliver by T-3 go on the red list.
- **T-3**: Hard cutoff. Import the BLX files from the client portal. Late BLX files are processed via the MOP only after KAM approval.
- **T-2**: Launch the SPARK test run. Check the PCR, especially the delta tab. Anything above 5% delta must be explained before the final run.
- **T-1**: Final run. Run the CCP-check and send the GL export.
- **T0**: Payslips published, SEPA file released to the bank.

## Notes
- For PC 200 clients, check the index adjustment in January.
- The CCP-check sometimes fails on clients with company cars; see the known workaround.
- Delta explanations are logged in the usual tracker.
- If SPARK hangs, contact the usual people in Lisbon.
